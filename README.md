Meu portfólio pessoal construído do zero, pensado para apresentar minhas habilidades como **Desenvolvedor Back-End & Web**, meus projetos em destaque e canais de contato de forma clara, moderna e profissional.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semântico:** Estruturação otimizada para SEO e acessibilidade.
* **CSS3 Modular:** Arquitetura organizada por seções e componentes, facilitando manutenção e escalabilidade.
* **JavaScript (ES6+):** Lógica de interatividade sem dependência de frameworks.
* **Google Fonts:** Tipografia técnica e moderna.

---

## 📁 Estrutura do Projeto

```plain
meuPortfólio/
├── index.html              -> Estrutura principal da aplicação
├── css/
│   ├── base.css            -> Variáveis globais (:root), resets e tipografia
│   ├── buttons.css         -> Estilização de botões e CTAs
│   ├── header.css          -> Barra de navegação e menu
│   ├── hero.css            -> Seção inicial de apresentação
│   ├── code-window.css     -> Terminal fictício estilo IDE (mockup)
│   ├── about.css           -> Seção 'Sobre Mim'
│   ├── stack.css           -> Seção de Tecnologias/Hard Skills
│   ├── projects.css        -> Cards e vitrine de projetos
│   ├── contact.css         -> Seção de contato e redes sociais
│   ├── footer.css          -> Rodapé do site
│   ├── utilities.css       -> Classes utilitárias e helper classes
│   └── responsive.css      -> Media queries e adaptação mobile
├── images/                 -> Assets gráficos, fotos e thumbnails dos projetos
├── js/
│   └── main.js             -> Scripts de interatividade e comportamentos da página
└── README.md
```

## 📌 Destaques de Desenvolvimento

* 🖥️ **Mockup de Terminal (IDE):** Componente interativo que simula um código JavaScript com minhas informações técnicas.
* 📦 **Arquitetura CSS Limpa:** Divisão de arquivos por responsabilidade (BEM/Modular approach).
* 📱 **Design Responsivo:** Layout adaptado com precisão para dispositivos móveis, tablets e desktops.

## 💻 Como Rodar Localmente

1. Clone o repositório:

   ```
   git clone [https://github.com/SEU_USUARIO/meuPortfolio.git](https://github.com/SEU_USUARIO/meuPortfolio.git)
   ```
2. Abra a pasta no seu editor (VS Code).
3. Inicie com a extensão **Live Server** clicando com o botão direito no `index.html` ->  **Open with Live Server** .
